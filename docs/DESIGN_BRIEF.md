# Présentation des guides

Public : les étudiants et les deux instances Codex qui prépareront le laboratoire. But : comprendre la configuration proposée, exécuter une tâche attribuée après accord, puis conserver une preuve lisible.

Format : quatre PDF A4 issus des mêmes sources Markdown versionnées. Conserver l'identité des documents fournis : fond blanc, titres bleu marine, tableaux sobres bleu-gris. Arial/Segoe UI pour le texte et une police monospace pour les commandes. Corps 10 à 10,5 points, interligne environ 14 points, titres nettement différenciés, marges confortables. Pas de texte minuscule pour faire entrer une table.

Composition : statut de proposition, objectif, ressources/interfaces, étapes ordonnées, contrôles attendus et limites. Schéma simple du chemin réseau et tableaux d'accès. Les liens portent un titre lisible. Pas d'animation ; lecture et impression sont les usages.

Les originaux servent de références. Leur contenu et celui des anciens plans ne constituent ni une validation technique ni une autorisation d'exécution.
